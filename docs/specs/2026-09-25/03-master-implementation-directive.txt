CORE ENGINEERING RULES

Do not sacrifice existing production functionality.

Do not delete working functionality merely to simplify implementation.

Keep staging and production operational data isolated.

Keep demo, paper, prop and live execution modes explicitly isolated.

Use one canonical internal user identity.

Use one canonical asset registry.

Use explicit state machines for signals, orders and positions.

Use idempotency for all externally observable side effects.

Use deterministic hard risk controls.

LLMs must never bypass deterministic execution or risk controls.

Never assume a timed-out broker request failed.

Reconcile every broker order and position.

Never execute from stale market data.

Never silently substitute stale or lower-quality data when execution safety is affected.

Preserve full auditability.

Avoid look-ahead leakage and survivorship bias.

Keep model promotion separate from model training.

Do not use headline win rate as the primary optimization objective.

Evaluate expectancy, drawdown, profit factor, calibration, fees, slippage and risk-adjusted performance.
