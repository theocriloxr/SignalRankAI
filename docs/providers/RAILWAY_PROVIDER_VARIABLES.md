# SignalRankAI — Railway Provider Variables (per service)

Service boundaries: **front door** (Telegram webhook), **engine** (signal
generation/market data), **worker** (outcomes, paper trading, payments,
execution adapters). Market-data flags are read by all services for parity
reporting; credentials are scoped to the service that actually uses them.

No real values — variable names only. Execution and payout variables stay 0
everywhere unless a separate owner-approved canary procedure is run.
