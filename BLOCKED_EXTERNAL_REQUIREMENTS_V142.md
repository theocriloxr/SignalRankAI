# External Requirements Not Embedded in the Archive

The code intentionally does not contain or fabricate:

- Railway project access or deployed environment variables.
- PostgreSQL/Redis production credentials.
- Provider API keys or paid data licences.
- Telegram bot tokens or production webhook ownership.
- Paystack secret keys.
- Apple/Google developer accounts, certificates or signing keys.
- Expo project ID, APNs or FCM credentials.
- OAuth client credentials, verified email domain or SSO metadata.
- Legal/compliance approval for financial promotions, execution or copy trading.
- Evidence sufficient to claim a guaranteed 60–75% win rate.

These must be supplied and certified in staging. Live execution and payouts
remain disabled by default.
