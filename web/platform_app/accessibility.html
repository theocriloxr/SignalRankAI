Accessibility

SignalRankAI aims to keep core account, billing and trading-intelligence workflows usable across devices and assistive technologies, using WCAG 2.2 AA as the practical target.

Interface target

Keyboard access, visible focus, programmatic labels, meaningful status messages, responsive reflow, readable contrast and non-colour-only state cues should be preserved as the product changes.

Dense trading views

Tables, charts and evidence views can be information-dense. Where a visual element carries important meaning, the product should provide a text or data alternative sufficient to understand the state or action.

Report a barrier

Use Support and include the screen, device, assistive technology if relevant, and the task you were trying to complete. A reasonable alternative route should be provided where practicable.

Ongoing requirement

Accessibility is not a one-time certification. New components, broker integrations and mobile releases can introduce regressions and should be retested.
